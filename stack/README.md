# Stack - 动态顺序栈实现

## 项目简介

本项目使用 **C 语言** 实现了一个**基于动态数组的顺序栈**（Stack）。栈采用后进先出（LIFO）策略，数组容量在栈满时自动扩容为原来的 2 倍。

## 数据结构

| 字段 | 类型 | 说明 |
|------|------|------|
| `arr` | `STDataType*` | 动态数组，存储栈元素 |
| `top` | `int` | 栈顶索引（下一个待压入的位置） |
| `capacity` | `int` | 当前数组容量 |

## 接口函数

| 函数 | 功能 |
|------|------|
| `stackinit(s)` | 初始化栈，分配初始 4 个元素的空间 |
| `stackpush(s, x)` | 压栈：容量不足时 `realloc` 扩容为 2 倍 |
| `stackpop(s)` | 出栈：弹出并打印栈顶元素 |
| `stacktop(s)` | 获取并打印栈顶元素 |
| `stacksize(s)` | 获取并打印栈中元素个数 |
| `stackempty(s)` | 判断栈是否为空并打印结果 |
| `stackdestroy(s)` | 销毁栈，释放所有内存 |

```

```

## 编译运行

使用 **Visual Studio 2022**（MSVC v145 工具集，x64 平台）。

打开 `stack.slnx` 即可直接编译运行。

## 操作演示

```
压栈: 1 → 2 → 3 → 4
栈: 4 3 2 1 (栈顶→栈底)
出栈: 4
栈: 3 2 1 (栈顶→栈底)
```
