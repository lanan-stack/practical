# Queue - 带头节点链表队列实现

## 项目简介

本项目使用 **C 语言** 实现了一个**带头节点的链表队列**（Queue）。队列采用先进先出（FIFO）策略，使用头尾双指针（`front` / `rear`）实现 O(1) 的入队和出队操作。

## 数据结构

| 字段 | 类型 | 说明 |
|------|------|------|
| `front` | `QNode*` | 指向头节点（队首前驱） |
| `rear` | `QNode*` | 指向尾节点 |
| `size` | `int` | 队列元素个数 |

节点结构：`QNode`，包含 `data`（int）和 `next` 指针。

## 接口函数

| 函数 | 功能 |
|------|------|
| `QueueInit` | 初始化队列，分配头节点 |
| `QueueDestroy` | 销毁队列，释放所有节点 |
| `QueueEmpty` | 判断队列是否为空 |
| `QueueSize` | 打印队列元素个数 |
| `QueueFront` | 打印队头元素 |
| `QueuePush` | 入队（尾部插入） |
| `DeQueue` | 出队（删除队首数据节点） |
